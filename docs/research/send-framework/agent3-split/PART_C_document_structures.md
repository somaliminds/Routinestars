## C1 — ONE PAGE PROFILE (national person-centred format)

The exact headings **"what people like and admire about me / what's important to me / how best to support me"** are not themselves statutory but are the universally-adopted person-centred practice format in the UK. The Welsh Code explicitly endorses them (Code §22.16, §23.24). The English SEND Code uses the same frame (Code §9.66–9.67 — "what is important to" vs "what is important for" the child). The Scottish CSP regulations require "any other relevant information" (reg 3(1)(b)(iii)) which in practice uses this frame.

### C1.1 Recommended standard One Page Profile fields (cross-nationally adopted)

| Section | Field | Type | Statutory status |
|---|---|---|---|
| **1. What people like and admire about me** | Strengths, gifts, talents, things others value | Free text | GOOD PRACTICE (informed by SEND CoP 6.45, ALN Code 22.16(a)) |
| **2. What's important to me** | The child's own priorities, what gives them joy/safety | Free text | GOOD PRACTICE (SEND CoP 9.66; ALN Code 22.16(d), 23.22–23.24) |
| **3. How best to support me** | Communication preferences, sensory needs, regulation strategies | Free text | GOOD PRACTICE (SEND CoP 6.45, ALN Code 22.16(e)) |
| **4. (Wales) What is important for me** | What others judge the child needs | Free text | GOOD PRACTICE — explicitly listed in ALN Code 23.24 |
| **5. (Wales) What is working and should be built on** | Effective strategies in place | Free text | GOOD PRACTICE (ALN Code 23.24) |
| **6. (Wales) What is not working and needs to change** | Barriers and unmet need | Free text | GOOD PRACTICE (ALN Code 23.24) |
| **Header** | Name, "likes to be known as", communication mode (verbal / AAC / signing / Makaton / objects of reference / easy read), date completed, who contributed | | |

## C4 — EHC NEEDS ASSESSMENT REQUEST (England) and equivalents

**Source:** SEND CoP 9.8–9.16; C&FA 2014 s.36; SEND Regs 2014 regs 3, 4, 5. **Status: STATUTORY** (s.36 right) + **STATUTORY GUIDANCE** (Code).

| Element | Requirement |
|---|---|
| **Who can request** | The child's parent; a young person aged 16–25; a person acting on behalf of a school or post-16 institution (ideally with knowledge/agreement of parent/YP). Anyone else can **bring the child to the attention** of the LA (CoP 9.8–9.10) |
| **Form of request** | No prescribed national form, but LA must have a route; written request recommended |
| **LA duty on receipt** | Notify parent/YP in writing within 6 weeks whether an EHCNA is necessary (CoP 9.11); must consult parent/YP and give them the opportunity to provide views/evidence (CoP 9.12) |
| **LA must notify** | Parent/YP; relevant CCG (or NHS England); LA social care officers; early years manager (if applicable); headteacher / principal (CoP 9.13) |
| **Evidence the LA expects to see (CoP 9.14–9.15)** | (1) Evidence of attainment / developmental milestones / rate of progress; (2) Nature, extent and context of SEN; (3) Action already taken by the setting to meet SEN; (4) Progress only as a result of much additional intervention over and above that usually provided; (5) Physical, emotional and social development and health needs; (6) For over-18 YP — whether additional time is required compared to the majority of others of the same age |
| **The setting's evidence (parent's request)** | APDR cycles; provision maps; intervention logs; progress data; outside-agency reports; IEPs/IHPs |
| **The setting's evidence (school's request)** | As above, plus the headteacher's view; the school's records; data on progress, attainment, attendance, behaviour; parental engagement; reasons why the school believes an EHCNA is needed |
| **Time limit** | LA must decide and communicate within **6 weeks** of receiving the request (CoP 9.11) |
| **Refusal rights** | Parent/YP can appeal to the First-tier Tribunal (SEN and Disability) (CoP Ch 11) |

**Wales equivalent** — request for the LA to decide ALN / IDP: Code Chs 20 and 21; ALN Act 2018 s.12 (decisions) and s.13 (LA duty where ALN identified). No prescribed national request form; the maintained school/FEI/LA must decide within timescales set out in the Code.

**Scotland equivalent** — assessment request for a CSP: asp 4 s.8 — parent or young person may request the authority to establish whether the child/young person requires a CSP; authority must inform requester of the outcome; refusal can be appealed to the Additional Support Needs Tribunals for Scotland (asp 4 s.18).

**NI equivalent** — request for statutory assessment (Stage 4): Code Part III; SEN Regs (NI) 2005 r.5–11. The EA must seek advice on educational, medical, psychological, and social services matters. Refusal can be appealed to the Special Educational Needs and Disability Tribunal (SENDIST) (NI).

**Statutory anchors for non-verbal / AAC capture:**
- SEND Code para 1.13: "where the child has communication difficulties, particular efforts should be made to elicit the child's views about decisions that affect them" (STATUTORY GUIDANCE)
- ALN Code 23.18 (s.1A.10): explicitly records "means of communication — communication which is verbal, written, signed, visual, and/or electronic … use of visual aids, font size or use of Braille and whether any specialist equipment is required, such as specialist IT equipment. Some children or young people may require less formal means of communication to support participation. This could include, for example, the use of play or art." (STATUTORY GUIDANCE)
- asp 4 s.3 (Scotland): defines a child/YP as lacking capacity if unable to understand, retain, weigh, or communicate a decision; framework then routes decision-making to a parent, with the **views of the child still being sought and recorded as far as possible** (STATUTORY)
